# 📰 TechNews Today — Portal de Notícias Moderno

Este projeto é a entrega de um desafio prático de CSS avançado. O objetivo foi construir o layout de um portal de notícias (*TechNews Today*) utilizando apenas **HTML5** e **CSS3 puro**, focando em técnicas modernas de estilização e layout responsivo.

---

## 📸 Prévia do Projetos

O layout do portal conta com:
- **Header Glassmorphism:** Efeito de vidro fosco com transparência e desfocagem.
- **Título com Gradiente:** Efeito visual moderno no texto da logo.
- **Header Fixo (`position: sticky`):** Navegação sempre visível no topo da página.
- **Layout com CSS Grid:** Organização dos cards, vídeos e área de newsletter lado a lado em ecrãs maiores.
- **Design Responsivo:** Adaptado para dispositivos móveis via Media Queries.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estrutura fornecida)
- **CSS3** (Estilização pura — *Vanilla CSS*)

> ⚠️ **Regras do Desafio:** Sem a utilização de frameworks (Bootstrap, Tailwind, etc.), sem JavaScript e mantendo o ficheiro CSS otimizado e enxuto.

---

## 📋 Checklist de Requisitos do Desafio

- [x] Glassmorphism (`backdrop-filter`)
- [x] Gradiente aplicado ao texto (`background-clip: text`)
- [x] Layout com **CSS Grid**
- [x] Header com `position: sticky`
- [x] Media Query para adaptação em telemóveis / dispositivos móveis 📱
- [x] CSS otimizado (no máximo 50 linhas)
- [x] Apenas CSS puro (sem JS/Frameworks e sem alterar a estrutura HTML)
